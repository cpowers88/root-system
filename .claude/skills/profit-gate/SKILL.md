# Profit-Skill Gate

Every new profit idea passes through the gate BEFORE getting a page,
time, or money. The gate is the castle's, not this skill's — this
skill just runs it faithfully.

## Steps

1. Read `00-BRAIN\CASTLE\wiki\decision-rules\adding-a-profit-skill.md`
   — the live gate criteria. Do not run from memory.
2. Read `01-NORTH_STAR\NORTH_STAR.md` § tracks + `.ROOT\NOW.md` for
   current phase/load context (danger weeks = automatic HOLD for
   anything non-school).
3. Walk the idea through every gate criterion explicitly — one line
   per criterion: pass / fail / unknown.
4. Verdict: **PASS** (name the phase it serves, the service it
   unlocks, the proof project) · **HOLD** (name the unlock condition)
   · **REJECT** (name the failed criterion).
5. Log the verdict:
   - Watchtower-originated signals → `...projectSuccess\radar.md`
     (✅ GATED + reason)
   - Otherwise → today's DAILY block + the castle `wiki/log.md`
6. If PASS: propose the castle skill-page stub — Chris approves before
   it's created (castle autonomy covers statuses, not new pages).

## Rules

- No orphan skills: a PASS must name phase + service + proof project.
- One idea per run. A batch of ideas = multiple runs, ranked at the end.
- The gate never runs during danger weeks (Oct 5 – Nov 11, 2026)
  except for school-serving items.
