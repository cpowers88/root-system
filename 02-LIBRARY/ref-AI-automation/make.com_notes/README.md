research. The other 43 files are preserved vendor-documentation captures for

volatile claim against current official documentation before acting on it.

## Capture Boundary

The imported `docId:` links inside the vendor captures are Make Help Center IDs,
not local `.ROOT` links. Treat them as capture artifacts. Do not create local notes
to satisfy those IDs; use current official documentation when a linked topic is
needed. Preserve the captures as historical reference, update the landscape rep
when real use changes Chris's judgment, and route new source intake through the
owning wiki rather than adding more files here by default.
