Use **Undo** and **Redo&#x20;**&#x69;n the Scenario toolbar to reverse or reapply changes to scenarios, such as adding, moving, linking, or configuring modules. These help you avoid manual reconfiguration when testing iterations or correcting mistakes.&#x20;

## Undo and redo changes

Undo or redo changes with the **Undo&#x20;**&#x61;nd **Redo&#x20;**&#x62;uttons on the Scenario toolbar or keyboard shortcuts.&#x20;

### Use the Scenario toolbar

In the Scenario Builder, click **Undo&#x20;**&#x6F;r **Redo&#x20;**&#x6F;n the Scenario toolbar.&#x20;

![](https://archbee-image-uploads.s3.amazonaws.com/oAyFj2GHlBeBVWF5OAir2/KPMnpVVEgH1XfAUEOueQy-20260504-093854.png)

### Use keyboard shortcuts&#x20;

Use these keyboard shortcuts to undo and redo changes.

| **Shortcut**                          | **Action**                   |
| ------------------------------------- | ---------------------------- |
| **Windows**: Ctrl+Z &#xA;**Mac**: ⌘+Z | Undo a change to a scenario  |
| **Windows**: Ctrl+Y&#xA;**Mac**: ⌘+Y  | Redo a change to a scenario  |

## Types of changes covered

The table below outlines which changes you can undo and redo.&#x20;

| **Covered**                   | **Not covered**             |
| ----------------------------- | --------------------------- |
| Module additions or deletions | Scenario inputs and outputs |
| Module linking or unliking    | Scenario settings           |
| Module position on the canvas |                             |
| Field mappings                |                             |
| Field text                    |                             |
| Schedule settings             |                             |
| Filters                       |                             |
