# Physics Anki Import and Rotation

Import `Physics_Stages_01-03_Active.tsv` into Anki with note type **Basic** and
separator **Tab**, using the deck name `Physics::Active::Stages 1-3`.

Do not power through the older mixed Physics deck. Rename it in Anki to
`Physics::Archive::Pre-2026-07-14`; the existing TSV files remain source
reference, not the daily queue.

motion, and vectors). Stage 4 motion in two dimensions is preview-only until the
next physics flashcard session; do not import later-stage cards into the active
rotation.

`ADAPTIVE_REVIEW_LOG.md`. Suspend locked cards in Anki; do not delete their source.
