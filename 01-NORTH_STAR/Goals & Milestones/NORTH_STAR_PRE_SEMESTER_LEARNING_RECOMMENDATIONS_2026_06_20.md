## CSE / PYTHON LEARNING PLAN

### Summer Objective

Pre-run CSE 1321 enough that the semester becomes repetition, not first contact.

### Working Standard

By Aug. 24, be able to write small programs without needing to look up every line.

### Module Targets

| Target Area | Summer Standard |
|---|---|
| Input / output | Can read user input and print clean output |
| Variables | Can store and update values correctly |
| Types | Can distinguish strings, integers, floats, booleans |
| Expressions | Can write arithmetic and comparison expressions |
| Selection | Can use if / elif / else correctly |
| Repetition | Can use loops without getting lost |
| Functions | Can define, call, and return values from functions |
| Libraries | Can import and use basic Python libraries |
| Lists / tuples | Can store and process multiple values |
| Dictionaries | Can connect keys to values |
| Searching / sorting | Can understand the basic purpose and flow |
| OOP | Can understand class, object, attribute, and method at an intro level |

### CSE Block Structure

For a 60–90 minute Python block:

```text
10 min — read the problem or module target
10 min — write input/output/steps
35–50 min — code
10–15 min — debug and explain back
5 min — log next action
```

### CSE Rules

- Go to code quickly.
- Write input/output/steps before touching code.
- Do not spend the block watching videos unless blocked.
- Push to GitHub when applicable.
- Comment enough that future Chris can read it.
- If stuck, reduce the problem; do not change subjects.

### Weekly CSE Outputs

```text
- 3–5 small programs
- 1 lab-style problem
- 1 explain-it-back note
- 1 list of bugs or syntax mistakes
```

## PHYSICS LEARNING PLAN

### Summer Objective

Build the mechanics foundation before Fall 2026 starts.

### Working Standard

Every physics problem starts with a diagram before equations.

### Physical Anchor Rule

Every new physics concept must be connected to something physical.

Examples:

```text
Position = where something is
Velocity = how position changes
Acceleration = how velocity changes
Force = interaction that changes motion
Energy = stored ability to cause motion/change
```

### Topic Targets

| Physics Area | Summer Standard |
|---|---|
| Units | Can convert and track units correctly |
| Dimensional analysis | Can check whether an equation makes sense |
| Vectors | Can split motion into x and y components |
| 1D kinematics | Can solve straight-line motion problems |
| 2D motion | Can separate horizontal and vertical motion |
| Projectile motion | Can identify independent x/y behavior |
| Newton’s laws | Can draw force diagrams and apply F = ma |
| Friction / inclines | Can solve basic cases with diagrams |
| Work / energy | Can identify conservation and energy transfer |

### Physics Block Structure

For a 60–90 minute Physics block:

```text
10 min — concept review
10 min — diagram setup
35–50 min — solve problems by hand
10–15 min — check answers and log errors
5 min — write next problem target
```

### Physics Rules

- No diagram, no equation.
- Work by hand first.
- Track mistakes in an error log.
- Prioritize mixed practice once basics are stable.
- If tired, do one clean hand-solved problem. That counts.

### Weekly Physics Outputs

```text
- 15–25 solved problems
- 1 updated error log
- 1 formula/concept sheet update
- 1 mixed problem set once ready
```
