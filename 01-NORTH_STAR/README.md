## What This Folder Is

The mission layer. Everything in here connects directly to October 8,
2031 — which is a **floor, not a finish line** (see The Ratchet in
NORTH_STAR.md). It is not a project folder. It is not a library. It
answers: **where are we going, and how are we tracking against it?**

The command-center wiki that executes this star lives at
`00-BRAIN\CASTLE\` (phases, skills, proof projects). The daily page it
maintains is `.ROOT\NOW.md`.

## Monthly Review Checklist

First session after the 1st of each month. 15–20 minutes.

1. **Pull the weeklies.** Read the month's handoffs and weekly
   reviews. Don't summarize — look for patterns.
2. **Score the three tracks + Personal.** School / Tech / Business /
   Personal. Hit / Partial / Miss. One honest line each.
3. **Run the weak-link question.** SKILL_GAP_ANALYSIS.md — is the
   current #1 gap still right?
4. **Check SYSTEM_FLAGS.md.** LOW flags get fixed this session.
   Anything raised twice in the month gets fixed this session.
5. **Advance the frontiers.** Update current-position in CASTLE,
   EDUCATION, and PHYSICS; move timeline tags forward where stages
   cleared (Tag Standard — WHERE_IT_GOES.md; graph colors are
   per-section and never hand-edited).
6. **Update core files if promotion is earned.** CHRIS.md,
   AGENT.md, capability profiles + hats, vault_map, WHERE_IT_GOES — only for lessons
   that repeated. Weeklies flag; monthlies fix.
7. **Set next month's three priorities.** Maximum three. Ranked.
8. **North Star check.** One sentence: closer to October 8, 2031
   than last month — and is the star still pointed at the most
   profitable true north we know of?
9. **Output** `MONTHLY_[MONTH]_YEAR.md` → `Weekly Reviews\`.

## Quarterly Audit + The Ratchet

When three monthlies are complete: quarterly audit (end of September,
December, March, June). The quarterly reviews the plan itself — and
runs the **Ratchet Review** (HAT_OPERATOR.md skill): every floor that
fell early gets considered for a raise. Floors ratchet up, never
down, never mid-cycle. Output: `QUARTERLY_Q#_YEAR.md` → this folder.
