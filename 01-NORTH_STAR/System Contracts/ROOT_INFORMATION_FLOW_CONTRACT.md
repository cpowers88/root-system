# `.ROOT` Information Flow Contract

This file explains where information goes. It does not define another lifecycle. The Action Kernel in `ROOT_CAPABILITY_CONTRACT.md` is the only universal runtime loop; `WHERE_IT_GOES.md` owns file placement.

## The flow

```text
request or observation
→ choose TUTOR, VALUE, or system review
→ load one authoritative owner
→ verify relevant evidence and uncertainty
→ run the smallest justified action or test
→ measure what happened
→ update the owner only when truth changed
→ expose one next move in NOW only when it is currently active
```

## Ownership

- North Star and strategy truth → `01-NORTH_STAR`.
- Learning truth → the owning course wiki and supplied course evidence.
- Professional knowledge and research → the owning `03-WIKIS` hub.
- Active builds → the project or external repository.
- Business field evidence → BUSINESS, SYSTEMS, or REVENUE_LAB according to the claim.
- Reusable sanitized assets → `05-BUSINESS`.
- System conflicts → `SYSTEM_FLAGS.md` and the affected instruction owner.
- Current cross-system action → `NOW.md`.

CASTLE may point to these owners and record decisions or proof status. It does not copy their full evidence.

## Diagnostic trace

Use this only when work is stuck, contested, handed off, or crossing owner boundaries:

1. **Outcome** — required result and human authority.
2. **Owner** — exact file or external system holding truth.
3. **Evidence** — source, confidence, and unresolved uncertainty.
4. **Test/action** — next transformation and stop rule.
5. **Return** — result, measured movement, and next decision.

If one line cannot be answered, repair that missing link. Routine tutoring, research, and building do not need a trace document.

## Acceptance standard

The flow works when a fresh agent finds the correct owner without loading unrelated realms, returns evidence to that owner, and leaves only one current next action. New information states, duplicated dashboards, or required daily/weekly ceremonies need evidence and Chris's approval before becoming live.
