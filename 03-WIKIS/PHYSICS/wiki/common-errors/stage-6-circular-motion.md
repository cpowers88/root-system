# Common Errors — Stage 6: Circular Motion and Other Applications of Newton's Laws (Ch 6)

1. **Treating centripetal force as a separate "extra" force.** Centripetal acceleration is directed toward the center, but "centripetal force" is not a new kind of force — it is the NET result of real forces (tension, gravity, normal force) that happen to point toward the center. Never draw a separate arrow labeled "Fc" on a free body diagram.

2. **Confusing centripetal and centrifugal.** Centripetal acceleration (real) points inward. "Centrifugal force" (fictitious) is what you feel in a rotating frame — it is NOT a real force and should not appear in Newton's-law equations written in an inertial frame.

3. **Forgetting that uniform circular motion still has acceleration.** Speed is constant, but velocity direction changes continuously — so acceleration is non-zero and points toward the center. "Constant speed" ≠ "zero acceleration."

4. **Mixing up the centripetal acceleration formula.** ac = v²/r = ω²r. Common mistake: writing ac = v/r (missing the square) or ac = ω/r (wrong variable). Both components of the formula are worth memorizing.

5. **Not accounting for gravity in banked curves and vertical circles.** At the top of a loop, gravity AND the normal force both point downward (toward the center) — they add. At the bottom of a loop, gravity is down but the center is up, so the normal force must exceed gravity. Setting up the free body diagram correctly for each position around the loop is essential.

6. **Applying terminal velocity logic before it applies.** Terminal velocity (vt = √(2mg/bρA)) requires that drag equals weight — a steady-state condition reached only after extended fall time. Using it at the instant of release gives a wrong answer; drag grows from zero as speed increases.

7. **Assuming the normal force equals mg in circular motion.** N = mg only in the absence of acceleration. On a banked curve or at the top/bottom of a loop, N ≠ mg because there is a centripetal (inward) net force requirement. Always write ΣF = ma toward the center.

8. **Adding a fictitious force while solving from the ground frame.** F_fict = −ma_frame only belongs in the equation if you have chosen to analyze the problem from inside the accelerating frame itself. If you are the ground (inertial) observer — the default in this course — only real forces belong in ΣF = ma. See [[../concepts/accelerated-reference-frames]].

9. **In an elevator apparent-weight problem, forgetting that true weight (mg) never changes.** Only the scale reading (normal force n) changes with the elevator's acceleration. n = m(g ± a), never mg ± a.
