# Work-Energy Theorem

## Equation

```text
W_net = ΔK = K_f − K_i = ½mv_f² − ½mv_i²
```

## Meaning in Plain English

The net work done on an object by all forces equals the change in the object's kinetic energy. If net work is positive, the object speeds up. If net work is negative, the object slows down. If net work is zero, speed stays constant.

This theorem provides a scalar energy route to problems that would otherwise require vector force analysis over time.

## Variables

| Symbol | Meaning | Unit |
|---|---|---|
| W_net | net work done by all forces combined | J |
| ΔK | change in kinetic energy | J |
| K_f | final kinetic energy = ½mv_f² | J |
| K_i | initial kinetic energy = ½mv_i² | J |
| m | mass | kg |
| v_f | final speed | m/s |
| v_i | initial speed | m/s |

## Units Check

W_net: [N][m] = J. ΔK: [kg][m²/s²] = J. Both sides: J = J ✓

## When to Use It

- When you know or can compute the work done by each force and want to find the final speed.
- When you know initial and final speeds and want to find net work or the work done by a specific force.
- When force analysis is complex but the displacement is known — skip finding acceleration, use W directly.

## When Not to Use It

- When you need details of the *motion* (time, acceleration as a function of position) — kinematics equations are better there.
- When thermal energy generated by friction is what you care about — use the full energy conservation framework (Stage 8).
- When the object rotates without translating — need rotational form.

## Required Assumptions

No restriction on whether forces are conservative or not — W_net = ΔK always holds. It is NOT limited to conservative forces (that limitation applies to potential energy).

## Calculus Origin

Derived directly from Newton's second law + integration:

```text
W_net = ∫F_net dx = ∫ma dx = ∫m(dv/dt)dx = ∫mv dv = ½mv²|ᵥᵢᵛ⁼ = ½mv_f² − ½mv_i²
```

## Procedure

1. Identify all forces on the object.
2. Compute work done by each force: W = Fd cos θ (or ∫F dx if varying).
3. Sum all individual works: W_net = W₁ + W₂ + ...
4. Set equal to ΔK: W_net = ½mv_f² − ½mv_i².
5. Solve for the unknown (usually v_f or d).

## Example Problem Type

"A 4.0 kg block starts from rest and a net horizontal force of 12 N acts over 5.0 m. Find the final speed."
→ W_net = 12 × 5.0 = 60 J. W_net = ΔK → 60 = ½(4.0)v_f² → v_f² = 30 → v_f = 5.5 m/s.

## Common Mistake

Computing the work done by only one force instead of the *net* work. Normal force and gravity do zero work on a horizontal surface — friction does negative work — the applied force does positive work. Sum them all.
