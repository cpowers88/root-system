# Equation — Vector Addition by Components

## Equation

```
R⃗ = A⃗ + B⃗
Rx = Ax + Bx
Ry = Ay + By
|R⃗| = √(Rx² + Ry²)
θR = tan⁻¹(Ry / Rx)
```

For three or more vectors: Rx = Ax + Bx + Cx + …, Ry = Ay + By + Cy + …

## Plain-English Meaning

To add vectors, add their x-components together and their y-components together. The result is a new vector (the resultant) whose components are those sums. You then find the resultant's magnitude and direction from its components.

## Variables

| Symbol | Meaning | Unit |
|---|---|---|
| A⃗, B⃗ | vectors being added | same as the physical quantity |
| R⃗ | resultant vector (the sum) | same as A and B |
| Rx, Ry | x and y components of R | same as A and B |
| θR | angle of R from +x axis | degrees |

## When to Use

Whenever you need to find the net result of two or more vector quantities (net force, net displacement, net velocity). This is the standard method — always use components unless the vectors are parallel or the problem explicitly asks for the graphical (tip-to-tail) method.

## When NOT to Use

Do NOT add magnitudes: |A⃗ + B⃗| ≠ A + B in general. Magnitude addition works only when the vectors point in exactly the same direction.

## Assumptions

Vectors must be in the same vector space (you can add two force vectors or two displacement vectors, but "force + displacement" is meaningless).

## Calculus Origin

No calculus. This is algebraic addition applied component by component. Calculus enters when vectors become functions of time (Stage 4).

## Example Problem Type

Adding two displacement vectors to find the shortest straight-line path back to the start; finding net force in Newton's 2nd law problems (Stage 5).

## Common Mistake

Forgetting to decompose before adding — trying to add magnitudes directly, or adding the angles. The component method is the only reliable general approach.
