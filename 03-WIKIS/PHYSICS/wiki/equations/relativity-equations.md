# Equation — Special Relativity

## Equations

**Lorentz factor (the central quantity of special relativity):**
```
γ = 1 / √(1 − v²/c²)     where c = 3.00×10⁸ m/s
γ ≥ 1 always; γ = 1 when v = 0; γ → ∞ as v → c
```

**Time dilation (moving clocks run slow):**
```
Δt = γ × Δt₀
Δt₀ = proper time (measured by the clock that MOVES with the event)
Δt  = dilated time (measured by the stationary observer) — always LONGER
```

**Length contraction (moving objects appear shorter):**
```
L = L₀ / γ
L₀ = proper length (measured in the rest frame of the object)
L  = contracted length (measured by moving observer) — always SHORTER
```

**Relativistic momentum:**
```
p = γmv    (replaces classical p = mv at high speeds)
```

**Energy equations:**
```
Rest energy:           E₀ = mc²
Total energy:          E  = γmc²
Relativistic KE:       K  = (γ−1)mc²    [NOT ½mv² at high speeds]
Energy-momentum:       E² = (pc)² + (mc²)²
```

## Plain-English Meanings

| Equation | What it says |
|---|---|
| γ formula | γ quantifies how relativistic an effect is. At v = 0.1c, γ ≈ 1.005 (tiny). At v = 0.9c, γ ≈ 2.3 (large). |
| Δt = γΔt₀ | A clock moving through space runs slow. The twin who travels fast ages less. |
| L = L₀/γ | An object moving past you appears shorter along its direction of motion. |
| E = γmc² | A moving object has more total energy than at rest — energy increases without bound as v → c. |
| E₀ = mc² | Even a stationary object has energy stored in its mass. |

## Common Mistake

Using K = ½mv² for relativistic particles. The correct form K = (γ−1)mc² reduces to ½mv² at low speeds (Taylor expansion), but diverges dramatically at v → c. Also: mixing up proper time and dilated time — the MOVING clock always reads less time.
