# Problem Type — Vector Addition

## How to Recognize It

Multiple vectors of the same physical type (all forces, all displacements, all velocities) must be combined to find a net/resultant vector. Signal words: "net force," "resultant displacement," "find the total."

## Typical Given Information

- Two or more vectors, each given as magnitude + angle, OR already as components.
- Sometimes the vectors are named (Team A pulls east, Team B pulls northeast…).

## Unknown Requested

- The resultant vector: magnitude and direction, or in component form.

## Diagram

Draw all vectors tip-to-tail (graphical method — useful for a sanity check) OR decompose all vectors onto the same coordinate axes (component method — required for accuracy).

## Equations

```
Rx = A_x + B_x + C_x + ...     (sum of x-components)
Ry = A_y + B_y + C_y + ...     (sum of y-components)
|R⃗| = √(Rx² + Ry²)
θ_R = tan⁻¹(Ry / Rx)  [adjust for quadrant]
```

## Solving Pattern

1. **Set up coordinates.** Label +x and +y clearly.
2. **Decompose every vector** into components (use Ax = A cos θ, Ay = A sin θ for each).
3. **Sum all x-components** → Rx. Sum all y-components → Ry.
4. **Find the resultant magnitude**: |R⃗| = √(Rx² + Ry²).
5. **Find the direction**: θ = tan⁻¹(Ry/Rx), adjust for quadrant.
6. **Write the answer** with units and direction.

## Unit Check

The resultant has the same units as each individual vector (adding forces gives a force, adding displacements gives a displacement).

## Common Traps

- Adding magnitudes directly (A + B ≠ |A⃗ + B⃗| in general).
- Forgetting that angles in Q2/Q3/Q4 produce negative components — the decomposition step handles this automatically if you use the angle from +x and let cos/sin carry the sign.
- Reporting the wrong quadrant for the resultant direction — always check the signs of Rx and Ry.

## Related Problem Types

Vector decomposition must be done first. This problem type feeds directly into Newton's 2nd law problems (Stage 5) and projectile motion (Stage 4).
