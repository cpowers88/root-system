# Dimensional Consistency Check

## How to Recognize This Problem Type

The problem says "show that this equation is dimensionally correct/consistent" or gives you an equation with unknown exponents and asks you to find them using dimensions — or you've derived a formula yourself and want to verify it before trusting it.

## Given Information Usually Present

An equation containing symbols, plus a statement of which physical quantity each symbol represents (e.g., "v represents speed, a represents acceleration, t represents time").

## Unknown Usually Requested

Whether the dimensions on both sides of the equation match — or, in the harder version, unknown exponents that make the dimensions match.

## Diagram to Draw

None. This is a symbolic/algebraic check, not a geometric one.

## Equations Commonly Used

- [v] = L/T
- [a] = L/T²
- [x] = L
- General rule: both sides of an equation must reduce to the same combination of L, M, T.

## Step-by-Step Solving Pattern

1. Write the dimension of every symbol in the equation using L, M, T (look them up if unfamiliar — don't guess).
2. Substitute these dimensions into the equation in place of the symbols.
3. Simplify both sides algebraically, treating L, M, T like algebra variables.
4. Compare: if both sides reduce to the exact same combination of L, M, T, the equation is dimensionally consistent. If not, it's wrong (or your exponents are wrong — solve for the exponents that make both sides match).

## Unit Checks

This entire problem type *is* a unit/dimension check — there's no separate step.

## Common Traps

- Trying to add or subtract terms with different dimensions (not allowed — dimensional analysis would catch this).
- Assuming dimensional consistency proves the equation is *fully* correct — it only proves the equation is *not provably wrong*. The numerical constant (like ½) is invisible to this check.
