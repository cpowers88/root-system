# Unit Conversion

## How to Recognize This Problem Type

A quantity is given in one unit system (or one specific unit), and the problem asks for the equivalent value in a different unit.

## Given Information Usually Present

A numeric value with units attached, and (implicitly or explicitly) the conversion factor between the given and desired units.

## Unknown Usually Requested

The same physical quantity, expressed in the new unit.

## Diagram to Draw

None.

## Equations Commonly Used

No physics equation — just conversion ratios such as 1 mi = 1609 m, 1 in. = 2.54 cm, 1 mile = 1.609 km.

## Step-by-Step Solving Pattern

1. Identify the unit you have and the unit you want.
2. Write the conversion factor as a fraction that equals 1, arranged so the unwanted unit is in the denominator (it will cancel against the given quantity's unit).
3. Multiply the given quantity by this fraction.
4. Cancel the matching units algebraically; confirm only the desired unit remains.
5. If the quantity has compound units (e.g., m/s), repeat for each part (length, then time) separately.

## Unit Checks

After multiplying, explicitly write out which units canceled and which remain — if the wrong unit is left over, the conversion factor was flipped.

## Common Traps

- Writing the conversion ratio upside down.
- Forgetting to convert *every* part of a compound unit (e.g., converting only the distance part of mi/h to km/h but not the time part).
- Mixing significant-figure precision from the conversion factor with the precision of the original measurement — exact conversions (like 1 in. = 2.54 cm exactly) don't limit significant figures; approximate ones (like 1 kg ≈ 2.2 lb) do.
