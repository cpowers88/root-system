# Terminal Velocity

**The constant speed reached by a falling object when the drag force equals its weight (net force = 0, so acceleration = 0).**

- Quadratic drag (standard): v_t = √(2mg / DρA)
- Linear drag (slow/small objects): v_t = mg/b
- Object approaches v_t exponentially — technically never exactly reaches it.
- A heavier object, a more aerodynamic shape, or thinner air all increase v_t.
- Skydivers typically reach ≈ 50–60 m/s (~180 km/h) in spread-eagle position; much higher in a tuck.
