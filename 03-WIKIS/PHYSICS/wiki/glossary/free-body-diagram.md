# Glossary — Free Body Diagram (FBD)

**Definition:** A diagram of a single object (drawn as a dot) with every force acting ON that object shown as a labeled arrow. Used as the essential first step in applying Newton's Second Law.

**Physical anchor:** Before writing any equation, you need to know what forces are present and in what direction. The FBD makes that visual and explicit so nothing is accidentally omitted or included wrongly.

**Rules:**
1. Draw the object as a dot.
2. Draw one arrow per force ON the object.
3. Label each arrow (n, w, T, f, F_app).
4. Never draw forces the object exerts on OTHER objects.
5. Choose and label a coordinate system.

**Why it works:** The FBD isolates the object from its environment. Each arrow represents an interaction with one other object. When you've captured all interactions, you have all the forces needed for ΣF = ma.
