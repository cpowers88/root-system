# Scalar

A physical quantity fully described by a single number and a unit, with no direction.

**Examples:** mass (kg), temperature (°C), speed (m/s), energy (J), time (s), distance (m).

**Contrast:** A vector requires magnitude AND direction. Speed is a scalar; velocity is a vector. Distance is a scalar; displacement is a vector.
