# Component

The projection of a vector onto a coordinate axis. For vector A⃗ at angle θ from the +x axis:

- x-component: Ax = A cos θ
- y-component: Ay = A sin θ

Components can be positive or negative depending on the quadrant. They carry the same unit as the vector's magnitude.

**Why components matter:** Because the x and y axes are perpendicular, the components are independent. This allows physics in 2D to be solved as two separate 1D problems run in parallel — the core trick behind projectile motion (Stage 4) and Newton's 2nd law in 2D (Stage 5).
