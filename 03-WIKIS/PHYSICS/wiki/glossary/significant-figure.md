# Significant Figure

## Plain-English Definition

A digit in a measured number that carries real meaning about how precisely the quantity was measured.

## Physics Meaning

The number of significant figures in a value reflects the precision of the measuring instrument used. Reporting more digits than were actually measured falsely implies extra precision.

## Units / Symbols If Applicable

N/A.

## Example

A length measured as 6.0 cm with a ruler accurate to ±0.1 cm has two significant figures.

## Common Confusion

Confusing the multiplication/division rule (count sig figs) with the addition/subtraction rule (count decimal places) — they are different rules.

## Flashcard

**Q:** When multiplying two measured numbers, how many sig figs should the answer have?
**A:** As many as the input with the *fewest* significant figures.
