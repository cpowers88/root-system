# Resultant

The single vector that is equivalent to the combined effect of two or more vectors. It is the vector sum.

**Symbol:** R⃗ = A⃗ + B⃗ + C⃗ + …

**How to find it:** Add components separately (Rx = Ax + Bx + …, Ry = Ay + By + …), then find magnitude |R⃗| = √(Rx² + Ry²) and direction θ = tan⁻¹(Ry/Rx).

**Physical use:** The net force on an object is the resultant of all individual forces. The resultant displacement is the straight-line path from start to end, regardless of the actual path taken.
