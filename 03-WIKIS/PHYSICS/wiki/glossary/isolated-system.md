# Isolated System (and Nonisolated System)

## Plain-English Definition

**Isolated system:** A system where no energy flows in or out from outside. Everything that matters is included inside the system boundary.

**Nonisolated system:** A system that exchanges energy with its surroundings — through work done by external forces, heat, friction losses, etc.

## Physics Meaning

- **Isolated (conservative forces only):** E_mech = constant → Ki + Ui = Kf + Uf
- **Nonisolated (friction or external work):** E_mech changes → ΔE_mech = W_external − f_k d

## Example

- **Isolated:** A pendulum swinging in vacuum — the Earth + pendulum system has no friction and no external forces doing work. E_mech is constant.
- **Nonisolated:** A block sliding on a rough floor — friction transfers energy from the system to the floor/environment as heat. E_mech decreases.

## Common Confusion

"Isolated" does not mean "nothing is touching the object." The normal force and gravity can both act on a block on a frictionless ramp — the system is still isolated because those forces are internal (gravity is between the object and Earth, which are both in the system) or perpendicular to motion (normal force does no work).

The system is **nonisolated** only when a force does *work* on it from outside — meaning the force has a component along the displacement.

## Flashcard

**Q:** What is the key difference between an isolated and a nonisolated system in energy problems?
**A:** Isolated: E_mech is conserved (conservative forces only). Nonisolated: E_mech changes because nonconservative forces (like friction) convert mechanical energy to thermal energy.
