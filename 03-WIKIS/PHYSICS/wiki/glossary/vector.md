# Vector

A physical quantity that requires both a magnitude and a direction to be fully described.

**Notation:** Written with an arrow above the symbol (v⃗, F⃗, a⃗) or in bold (**v**, **F**, **a**).

**Examples:** velocity (m/s, with direction), displacement (m, with direction), force (N, with direction), acceleration (m/s², with direction), momentum (kg·m/s, with direction).

**Components:** Any vector in 2D can be written as **A⃗ = Ax î + Ay ĵ**, where î and ĵ are unit vectors along +x and +y.
