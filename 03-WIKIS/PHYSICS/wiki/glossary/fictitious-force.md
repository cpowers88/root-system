# Fictitious Force (Pseudo-Force)

**A bookkeeping force, F_fict = −ma_frame, added only when analyzing motion from inside a noninertial (accelerating) reference frame — not a force exerted by any real object.**

- Points opposite the accelerating frame's own acceleration.
- "Centrifugal force" is the most common example — it appears only to an observer riding in a rotating frame; a ground (inertial) observer sees only the real, inward centripetal force.
- Never add a fictitious force when solving from the ground/inertial frame — that is the default choice in this course.

*First appears: Stage 6 (Ch 6.3). See [[../concepts/accelerated-reference-frames]].*
