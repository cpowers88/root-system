## The math-first operating system

Budget **9–11 focused hours outside class each week**:

1. **Pre-read (three blocks, 35–50 minutes each):** physical situation → diagram
   → variables/units → math relationship → symbolic derivation → one hidden-step
   worked example → three-question recall.
2. **Fresh private practice (two blocks, 45–60 minutes):** one worked, one faded,
   then one cold problem. These are wiki/generated practice, never WebAssign.
3. **Graded work (3–4 hours):** complete WebAssign independently and record only
   the error class afterward, not its problem text or answer.
4. **Recitation repair (60–90 minutes):** redo the underlying skill on a fresh
   problem within 24 hours.
5. **Durability (15–25 minutes):** cold recheck 48–72 hours later. Only durable
   proof advances [[current-position]].

For every problem, use: **model → diagram → known/unknown → symbolic equation →
solve algebraically → substitute → units/sign/limit check → second-road check**.

## Mastery scorecard

A topic is exam-ready only when Chris can, cold:

- select the model from words or a diagram without equation hunting;
- draw the governing diagram and define axes/signs;
- state or derive the central relationship and explain what its calculus means;
- solve symbolically before substituting numbers;
- pass units, sign/direction, and limiting-case checks;
- solve a second-road verification when one exists; and
- reproduce the skill 48–72 hours later.

Target three 100% cold passes at exam difficulty across separate sessions. Log
the evidence in [[log]]; a calendar date alone never advances a stage.
