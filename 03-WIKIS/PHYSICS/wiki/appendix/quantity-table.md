# Physical Quantities — Symbols, Dimensions, and Units

**Source:** Appendix A, Table A.2

This table maps every physical quantity used in PHYS 2211 to its symbol, dimensional formula, and SI unit. Dimensions use: M = mass, L = length, T = time, Q = charge, Θ = temperature.

Mechanics quantities (Stages 1–18) are marked **M**. E&M quantities are included for completeness but are PHYS 2212 material.

## Useful Dimensional Relationships

```
F = ma        → N = kg·(m/s²)            ✓ check: ML/T²
W = Fd        → J = N·m = kg·m²/s²       ✓ check: ML²/T²
P = W/t       → W = J/s = kg·m²/s³       ✓ check: ML²/T³
p = mv        → kg·m/s                    ✓ check: ML/T
τ = rF        → N·m = kg·m²/s²           ✓ check: ML²/T²
L = Iω        → kg·m²/s                  ✓ check: ML²/T
```

Note: torque (N·m) and energy (J = N·m) have the same dimensions but are **different physical quantities**. Torque is not energy.
