# Concept: Impulse

## What It Is

Impulse is the total "push" delivered to an object over time — the change in momentum it receives from a force:

```
J⃗ = ΔP⃗ = ∫ F⃗ dt
```

For a constant average force:

```
J⃗ = F⃗_avg · Δt
```

## Real-World Anchor

A karate chop and a gentle sustained push can move an object the same final speed, if F·Δt is equal. The karate chop is brief and violent; the push is slow and gentle — same impulse, same result. This is why air bags in cars work: they increase Δt during a collision, which reduces the peak force F needed to deliver the same impulse (the same Δp) to your body.

## Reading a F-t Graph

The area under a Force vs. time graph is the impulse. For complex force profiles:

```
J = area under F-t curve
```

For a rectangular (constant) force: area = F · Δt
For a triangular pulse: area = ½ · F_peak · Δt

## Units

N·s = kg·m/s (they are the same unit)

## Impulse-Momentum Theorem

Impulse equals the change in momentum:

```
J⃗ = Δp⃗ = p⃗_f − p⃗_i
```

This is the bridge between force (cause) and momentum change (effect).

## Common Confusion

Impulse is not the same as momentum. Impulse is a *transfer* of momentum — what one object delivers to another. Momentum is what an object *has*. After the transfer, the receiver's momentum increases by the amount of the impulse.
