# SI Base Units

## What is the physical idea?

Every physical quantity must be measured against an agreed-upon standard. In mechanics, all quantities reduce to just three fundamental ones: **length**, **mass**, and **time**. Everything else (speed, force, energy...) is built from these three.

## What real-world situation does it describe?

Any time you measure something — how far, how heavy, how long it took — you're using one of these three base quantities, or a combination of them.

## Objects / System Involved

No specific object. This is the measurement framework underneath every object and system you'll study this semester.

No equation. This is a definitional framework:

## Common Beginner Mistake

Treating mass and weight as the same thing. Mass (kg) is how much matter an object has; weight is a force (depends on gravity) and isn't introduced until Chapter 5. For now, just remember: kilogram = mass, not weight.
