# Stage 3 Textbook Problem Set — Serway & Jewett 10e, Chapter 3 (Vectors)

## Purpose

Real end-of-chapter problems (not generated ones), pulled directly from
`raw/textbook/Physics book-0001-0100.pdf` (Chapter 3, pp. 63-66; problems 1-32,
"Problems" section). This is the source-of-record set for working Chapter 3
problems as Stage 3 progresses — Chris flags which ones deserve the full
teaching/reflection treatment (stop, sketch, decompose, explain-back) versus a
quick independent solve.

Some problems reference a textbook figure (Figure P3.x) that isn't reproduced
here — open the raw PDF page to view it before attempting those. Extraction is
from OCR text, so if a number looks visually odd (e.g., a stray "08" instead
of ".0°"), verify against the raw PDF before treating it as authoritative.

## How to Use This Page

For each problem: attempt cold, no notes, using the Stage 3 skeleton
(sketch → decompose → add/operate → reconstruct). Mark the **Reflection?**
column when Chris flags a problem live in session as one to slow down on and
explain back rather than just solve. Leave blank otherwise.

## Section 3.3 — Basic Vector Arithmetic

| # | Problem | Reflection? |
|---|---|---|
| 6 | Vector A⃗ has a magnitude of 29 units and points in the +y direction. When vector B⃗ is added to A⃗, the resultant vector A⃗+B⃗ points in the −y direction with a magnitude of 14 units. Find the magnitude and direction of B⃗. | |
| 7 | A force F⃗₁ of magnitude 6.00 units acts on an object at the origin in a direction θ = 30.0° above +x. A second force F⃗₂ of magnitude 5.00 units acts on the object along +y. | 8 | Three displacements: A⃗ = 200 m due south, B⃗ = 250 m due west, C⃗ = 150 m at 30.0° east of north. (a) Construct a separate diagram for each possible order of adding these vectors: R⃗₁ = A⃗+B⃗+C⃗; R⃗₂ = B⃗+C⃗+A⃗; R⃗₃ = C⃗+B⃗+A⃗. (b) Explain what you can conclude from comparing the diagrams. | |
| 9 | Displacement vectors A⃗ and B⃗ (Figure P3.9) both have magnitude 3.00 m. The direction of A⃗ is θ = 30.0°. Find graphically (a) A⃗+B⃗, (b) A⃗−B⃗, (c) B⃗−A⃗, (d) A⃗−2B⃗. Report all angles counterclockwise from +x. *(Requires Figure P3.9 for B⃗'s direction.)* | |
| 10 | A roller-coaster car moves 200 ft horizontally, then rises 135 ft at 30.0° above horizontal, then travels 135 ft at 40.0° downward. Find its displacement from the starting point (graphical technique). | |

## Section 3.4 — Components of a Vector and Unit Vectors

| # | Problem | Reflection? |
|---|---|---|
| 11 | A minivan travels straight north at 28.0 m/s. A camper changes lanes into a straight displacement at 8.50° east of north, without decreasing the north-south gap to the minivan's front bumper. (a) Can this be done? (b) Explain. (Conceptual/geometric — good one for explain-back.) | |
| 12 | A person walks 25.0° north of east for 3.10 km. How far would she have to walk due north and due east to arrive at the same location? (Decomposition, direct application.) | |
| 13 | A dog undergoes successive displacements: 3.50 m south, 8.20 m northeast, 15.0 m west. Find the resultant displacement. (Three-vector addition — good bridge to the addition drill's Part C.) | |
| 14 | Given A⃗ = 2.00î + 6.00ĵ and B⃗ = 3.00î − 2.00ĵ: (a) draw the vector sum C⃗ = A⃗+B⃗ and the vector difference D⃗ = A⃗−B⃗; (b) calculate C⃗ and D⃗ in terms of unit vectors; (c) calculate C⃗ and D⃗ in polar form (angle from +x). | |
| 17 | Given A⃗ = (3î − 3ĵ) m, B⃗ = (î − 4ĵ) m, C⃗ = (−2î + 5ĵ) m. Use the component method to find (a) magnitude and direction of D⃗ = A⃗+B⃗+C⃗, and (b) magnitude and direction of E⃗ = −A⃗−B⃗+C⃗. (Direct fit for the addition-by-components skill — good default pick.) | |
| 18 | Vector A⃗ has components (−8.70, 15.0) cm; vector B⃗ has components (13.2, −6.60) cm. If A⃗ − B⃗ + 3C⃗ = 0, find the components of C⃗. (Algebra-on-vectors — solve for the unknown component-wise.) | |
| 19 | Vector A⃗ has x, y, z components 8.00, 12.0, −4.00 units. (a) Write A⃗ in unit-vector notation. (b) Find B⃗, one-fourth the length of A⃗, same direction. (c) Find C⃗, three times the length of A⃗, opposite direction. (3D unit-vector scaling.) | |
| 21 | Vector A⃗ has a negative x component 3.00 units long and a positive y component 2.00 units long. (a) Write A⃗ in unit-vector notation. (b) Find the magnitude and direction of A⃗. (c) Find B⃗ such that A⃗+B⃗ has zero x-component and a negative y-component of 4.00 units. (Good reflection candidate — part (c) requires solving backward from a target resultant.) | |
| 24 | Vector B⃗ has x, y, z components 4.00, 6.00, 3.00 units. Calculate (a) the magnitude of B⃗ and (b) the angle B⃗ makes with each coordinate axis. (3D magnitude/direction-cosine extension — beyond the 2D mastery checklist but good stretch once 2D is solid.) | |
| 25 | Use the component method to add vectors A⃗ and B⃗ from Figure P3.9 (both magnitude 3.00 m, A⃗ at θ = 30.0°). Express A⃗+B⃗ in unit-vector notation. *(Companion to problem 9 — same setup, component method instead of graphical.)* | |
| 26 | A girl delivering newspapers travels 3.00 blocks west, 4.00 blocks north, then 6.00 blocks east. (a) Find her resultant displacement. (b) Find the total distance she travels. (Distance vs. displacement — ties back to the scalar/vector ID skill.) | |
| 27 | A man pushing a mop causes two displacements. The first has magnitude 150 cm at 120° from +x. The resultant displacement has magnitude 140 cm at 35.0° from +x. Find the magnitude and direction of the second displacement. (Solve for one addend given the sum — good reflection candidate, inverse of the standard addition problem.) | |
| 31 | *Review.* You stand at the origin. A plane flies parallel to the x axis at constant velocity, height 7.60×10³ m. At t=0 the position vector to it is P⃗₀ = 7.60×10³ĵ m. At t=30.0 s, P⃗₃₀ = (8.04×10³î + 7.60×10³ĵ) m. Determine the magnitude and direction of the plane's position vector at t=45.0 s. *(Requires recognizing constant-velocity x-motion — light bridge into Stage 4, good one to flag if attempted before Stage 4.)* | |
