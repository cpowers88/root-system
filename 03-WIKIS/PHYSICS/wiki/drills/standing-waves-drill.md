# Standing Waves Drill

## Skill Being Practiced

Finding allowed wavelengths, harmonic frequencies, and wave speeds for strings and air columns; identifying nodes and antinodes.

## Prerequisites

[[../concepts/standing-waves]], [[../equations/standing-wave-string]], [[../equations/harmonic-frequencies-string]], [[../equations/standing-wave-open-pipe]], [[../equations/standing-wave-closed-pipe]]

## Key Equations

```
String (both ends fixed) or Open pipe (both ends open):
  λ_n = 2L/n          (n = 1, 2, 3, ...)
  f_n = nv/(2L) = n·f₁

Closed pipe (one closed end, one open end):
  λ_n = 4L/n          (n = 1, 3, 5, ... odd only)
  f_n = nv/(4L)
```

Wave speed on a string: v = √(F_T/μ), where F_T = tension, μ = mass/length.
Speed of sound in air at room temperature: v_sound ≈ 343 m/s.

## Problems

### Part A — Strings (both ends fixed)

1. A guitar string is 0.65 m long. The wave speed is 440 m/s. Find the fundamental frequency and the first three harmonics.

2. A string of length 1.20 m resonates at 200 Hz. What is the wave speed if this is the 3rd harmonic?

3. A string vibrates in its 4th harmonic mode. Sketch the standing wave pattern. How many nodes and antinodes are present?

4. A 0.80 m string has a linear mass density μ = 0.005 kg/m and is under 200 N of tension. Find the fundamental frequency.

### Part B — Open Pipes (both ends open)

5. An open pipe is 1.70 m long. Using v = 343 m/s, find f₁, f₂, and f₃.

6. An open pipe resonates at 680 Hz and at 850 Hz (two consecutive harmonics). Find the fundamental frequency and the pipe length.

### Part C — Closed Pipes (one closed end)

7. A pipe closed at one end is 0.85 m long. Find the three lowest resonant frequencies. (Use v = 343 m/s.)

8. A clarinet (approximate model: closed pipe) resonates at 150 Hz as its lowest note. What is its effective length?

9. Why does a closed pipe only produce odd harmonics? Explain in terms of node/antinode conditions at each end.

### Part D — Mixed

10. A 1.50 m string (v = 300 m/s) vibrates. A microphone detects resonances at 100 Hz, 200 Hz, and 300 Hz. Are these consecutive harmonics? What is f₁?

## Check Yourself

Problem 1: f₁ = v/(2L) = 440/(2×0.65) = 338 Hz; f₂ = 677 Hz; f₃ = 1015 Hz; f₄ = 1354 Hz
Problem 5: f₁ = 343/(2×1.70) = 100.9 Hz; f₂ = 201.8 Hz; f₃ = 302.6 Hz
Problem 7: f₁ = 343/(4×0.85) = 100.9 Hz; f₃ = 302.6 Hz; f₅ = 504.4 Hz (only odd harmonics)

## Mastery Signal

Chris can find fundamental frequency and harmonics for any string or pipe, sketch the correct standing wave pattern for each harmonic, and explain why closed pipes only have odd harmonics — without looking at a formula sheet.
