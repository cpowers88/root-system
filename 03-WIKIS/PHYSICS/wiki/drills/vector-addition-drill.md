# Vector Addition Drill

## Skill Being Practiced

Adding and subtracting vectors by components; finding the magnitude and direction of a resultant vector.

## Prerequisites

[[../drills/vector-components-drill]], [[../concepts/vector-components]]

## Instructions

For each problem: (1) find all components separately, (2) add x-components, add y-components, (3) find magnitude and direction of the resultant.

## Problems

**Part A — Add two vectors**

1. A⃗ = 3.0î + 4.0ĵ m, B⃗ = 1.0î + 2.0ĵ m. Find R⃗ = A⃗ + B⃗, |R⃗|, and the angle θ from +x.

2. P⃗ has magnitude 5.0 N at 37° above +x; Q⃗ has magnitude 10.0 N at 53° above +x. Find R⃗ = P⃗ + Q⃗. (Hint: decompose each first.)

3. A⃗ = 6.0î − 3.0ĵ m/s, B⃗ = −2.0î + 5.0ĵ m/s. Find A⃗ + B⃗.

**Part B — Subtract vectors**

4. A⃗ = 5.0î + 2.0ĵ m, B⃗ = 3.0î − 1.0ĵ m. Find A⃗ − B⃗.

5. A displacement vector takes you 4.0 m east then 3.0 m north. A second path takes you 2.0 m east then 5.0 m north. Find the vector from the endpoint of path 1 to the endpoint of path 2. (This is path2 − path1.)

**Part C — Add three vectors**

6. A⃗ = 2.0î + 3.0ĵ N, B⃗ = −1.0î + 4.0ĵ N, C⃗ = 3.0î − 2.0ĵ N. Find the net force F⃗ = A⃗ + B⃗ + C⃗.

7. Three displacement vectors: 10 m east (0°), 6 m at 120°, 5 m at 240°. Find the resultant displacement.

**Part D — Conceptual check**

8. Can two nonzero vectors A⃗ and B⃗ add to zero? If yes, what is the geometric relationship between them?

9. A⃗ has magnitude 5 and B⃗ has magnitude 3. What are the maximum and minimum possible magnitudes of A⃗ + B⃗?

## Check Yourself

Problem 1: R⃗ = 4.0î + 6.0ĵ m; |R⃗| = √(16+36) = 7.21 m; θ = tan⁻¹(6/4) = 56.3° above +x.
Problem 3: R⃗ = 4.0î + 2.0ĵ m/s.
Problem 6: F⃗ = 4.0î + 5.0ĵ N; |F⃗| = √(16+25) = 6.4 N; θ = tan⁻¹(5/4) ≈ 51.3° above +x.
Problem 8: Yes — if A⃗ and B⃗ are equal in magnitude and exactly opposite in direction (antiparallel), A⃗ + B⃗ = 0.
Problem 9: Maximum = 8 (parallel, same direction); minimum = 2 (antiparallel, opposite direction).

## Mastery Signal

Chris can set up and solve a three-vector addition problem from scratch in under three minutes, including finding the resultant magnitude and direction, without errors.
