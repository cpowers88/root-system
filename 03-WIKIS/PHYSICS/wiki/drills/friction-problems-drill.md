# Friction Problems Drill

## Skill Being Practiced

Correctly applying static and kinetic friction models, including identifying which type is active and computing the friction force.

## Prerequisites

[[../concepts/friction]], [[../equations/static-friction]], [[../equations/kinetic-friction]], [[../drills/fbd-drawing-drill]]

## Instructions

For each problem: state which friction type applies, compute the normal force, compute the friction force, and then apply Newton's 2nd Law. Show all units.

## Problems

**Problem 1 — Is it moving?**
A 5.0 kg box sits on a surface with μ_s = 0.50, μ_k = 0.35. You push horizontally with 20 N. (a) Does the box move? (b) What is the friction force?
*(g = 9.80 m/s²; max static = μ_s × mg = 0.50 × 49 = 24.5 N. Since 20 N < 24.5 N, the box does NOT move. Friction = 20 N exactly, opposing the push.)*

**Problem 2 — Kinetic friction.**
Same box, same surface. You now push with 35 N. Find the acceleration.
*(Since 35 N > 24.5 N, it moves. f_k = 0.35 × 49 = 17.2 N. a = (35 − 17.2)/5 = 3.56 m/s²)*

**Problem 3 — Friction on an incline.**
A 3.0 kg block rests on a 20° incline with μ_s = 0.40. Will the block slide?
*(mg sin20° = 10.04 N; max static = μ_s × mg cos20° = 0.40 × 27.6 = 11.05 N. Since 10.04 N < 11.05 N, the block does NOT slide.)*

**Problem 4 — Kinetic friction on incline.**
Same block, same incline, μ_k = 0.25. The block is given a push and starts sliding down. Find the acceleration.
*(Along slope: mg sin20° − f_k = ma; f_k = 0.25 × mg cos20°. Solve for a.)*

**Problem 5 — Finding μ_k from experiment.**
A 2.0 kg block slides at constant velocity when pushed horizontally with 6.0 N across a level surface. Find μ_k.
*(Constant velocity → a = 0 → ΣF = 0. So f_k = 6.0 N. n = mg = 19.6 N. μ_k = 6.0/19.6 = 0.306.)*

**Problem 6 — Minimum force to start moving.**
What horizontal force is needed to just barely start moving a 10 kg refrigerator (μ_s = 0.60) across a level floor?
*(F_min = μ_s × n = 0.60 × 98 = 58.8 N)*

**Problem 7 — Stacked blocks.**
Block A (2 kg) sits on top of block B (5 kg). μ_s between A and B = 0.30; floor under B is frictionless. A horizontal force of 9 N is applied to block B. (a) Do the blocks move together? (b) If yes, find acceleration.
*(Max friction from B on A = μ_s × m_A × g = 0.30 × 2 × 9.80 = 5.88 N. If they move together, a = 9/7 = 1.29 m/s². Force needed on A = m_A × a = 2 × 1.29 = 2.57 N < 5.88 N. Yes, they move together. a = 1.29 m/s².)*

## Mastery Signal

Chris can correctly identify static vs. kinetic friction for any scenario and compute it without looking up the procedure.
