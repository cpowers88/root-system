# Dimensional Analysis Drill

## Skill Being Practiced

Checking whether an equation is dimensionally consistent, and solving for unknown exponents using dimensions.

## Prerequisites

[[../concepts/dimensional-analysis]], [[../concepts/si-base-units]]

## Instructions

For each equation, write the dimension of every symbol, substitute, and simplify both sides. State whether the equation is dimensionally consistent. Show your work — don't just state yes/no.

## Problems

1. Is x = ½at² dimensionally correct, given [x] = L, [a] = L/T², [t] = T?
2. Is v = at dimensionally correct, given [v] = L/T?
3. A formula claims a = krⁿvᵘ for a particle in circular motion, where r is radius (L) and v is speed (L/T), and k is dimensionless. Find n and m so the equation is dimensionally consistent with [a] = L/T².
4. Is the equation y = v₀t + bt³ dimensionally possible if y has dimension L and t has dimension T? What must the dimension of b be?
5. Check whether F = mv² / r could represent a force, given [F] should be ML/T², [m] = M, [v] = L/T, [r] = L.

## Check Yourself

Problem 1: L = (L/T²)(T²) = L ✓. Problem 3: n = -1, m = 2 (matches the textbook's centripetal acceleration form a = v²/r). Problem 5: ML/T² = M(L/T)²/L = ML/T² ✓ — dimensionally plausible.

## Mastery Signal

Chris can do a dimensional check on a never-seen-before equation in under two minutes, without looking up the dimension table.
