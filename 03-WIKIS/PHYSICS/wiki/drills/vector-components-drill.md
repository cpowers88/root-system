# Vector Components Drill

## Skill Being Practiced

Decomposing a vector into x and y components using trigonometry, and reconstructing a vector from its components.

## Prerequisites

[[../concepts/scalar-vs-vector]], [[../concepts/vector-components]], [[../appendix/math-geometry-trig]]

## Instructions

For each problem: (1) draw a coordinate system and sketch the vector, (2) label the angle, (3) compute the components, (4) check with the Pythagorean theorem.

## Problems

**Part A — Find the components**

1. A⃗ has magnitude 8.0 m at 30° above the +x axis. Find Ax and Ay.

2. B⃗ has magnitude 12.5 N at 60° above the +x axis. Find Bx and By.

3. C⃗ has magnitude 5.0 m/s at 45° below the +x axis (4th quadrant). Find Cx and Cy. (Note: Cy is negative.)

4. D⃗ has magnitude 20.0 m at 120° from the +x axis (2nd quadrant). Find Dx and Dy. (Hint: cos 120° is negative.)

5. E⃗ has magnitude 15 N pointing straight up (+y direction). Find Ex and Ey without a calculator.

**Part B — Reconstruct from components**

6. Fx = 6.0 m, Fy = 8.0 m. Find the magnitude and direction (angle from +x axis) of F⃗.

7. Gx = −3.0 N, Gy = 4.0 N. Find |G⃗| and θ. (Note: vector is in 2nd quadrant — add 180° to calculator output.)

8. Hx = 5.0 m/s, Hy = −5.0 m/s. Find |H⃗| and θ.

9. A vector has magnitude 13.0 m and angle 67.4° from the +x axis. Verify by computing components and then reconstructing the magnitude. (Hint: 5-12-13 right triangle.)

**Part C — Unit vector notation**

10. Write A⃗ from Problem 1 in unit-vector notation (î and ĵ form).
11. Write G⃗ from Problem 7 in unit-vector notation.

## Check Yourself

Problem 1: Ax = 8.0 cos 30° = 6.93 m, Ay = 8.0 sin 30° = 4.0 m.
Problem 4: Dx = 20.0 cos 120° = −10.0 m, Dy = 20.0 sin 120° = 17.3 m.
Problem 6: |F⃗| = √(36+64) = 10.0 m; θ = tan⁻¹(8/6) = 53.1° above +x.
Problem 7: |G⃗| = √(9+16) = 5.0 N; calculator gives tan⁻¹(4/−3) ≈ −53.1°, but since Gx < 0 and Gy > 0, the vector is in Q2; correct angle = 180° − 53.1° = 126.9°.

## Mastery Signal

Chris can decompose any vector given as magnitude+angle and reconstruct any vector given as components, in under 90 seconds per problem, without looking at notes.
