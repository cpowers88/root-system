# EDUCATION

This wiki supports KSU courses that do not yet need a dedicated subject wiki.
It turns official requirements and supporting sources into usable study maps,
explanations, drills, flashcards, and reading guides.

Start with:

1. `HOW_TO_USE.md` for the human workflow.
2. `wiki\current-position.md` for current course status.
3. `wiki\index.md` for the complete catalog.

Official school files remain in `04-SCHOOL`. Python/CSE and Physics
belong to their dedicated wikis.
