# Open TC Page Map — *Open Technical Communication*, 4th ed.

**What this owns:** the chapter/section → **physical PDF page** mapping for the assigned
TCOM 2010 textbook, so a citation is a retrieval instead of a search.

**What it does not own:** *what to read when* — that is [[semester-map]] and
[[tcom-2010-17-week-execution-plan]], and the cross-course assembly in
`04-SCHOOL\semester-reading-plan.md`.

Built 2026-08-19 to match the page discipline PHYSICS and PYTHON already had
(`PHYSICS\wiki\textbook-page-map.md`, `PYTHON\wiki\source-page-map.md`). TCOM was the
only lettered course whose readings could be cited by chapter alone.

---

## The one thing to know before opening it

> **There is no offset. The number in your reader's page box is the number in this table.**

This book is a Manifold web export and **carries no printed page numbers at all** — no
front-matter roman numerals, no printed folios. Its own Table of Contents (physical p. 7)
already references physical PDF pages, which is why every row below could be cross-checked
against the book's own index rather than inferred.

That makes it the *simplest* of the three course texts to cite, and the opposite of Serway,
where PDF page = printed page + 30.

**File:** `03-WIKIS\EDUCATION\raw\Open-TC_Course-Resources\Open-TC-PDF.pdf` · **634 physical
pages**. **This map is valid for that file and no other.**

🔴 **Corrected 2026-08-21.** This line previously called
`raw\Textbook Doc Files\Open Technical Communication.pdf` a "duplicate titled copy." **It is
not a duplicate.** It is a **353-page SoftChalk web print-out** of the same edition —
same chapters, completely different pagination, and no page numbers of its own. Verified by
extraction: in the 634-page file p149 is *2.13 Memos and Emails* and p174 is *Ch 3 Ethics*;
in the 353-page file p149 is *Writing Process* and p174 is *Audience Analysis*. **Every page
number below is wrong by roughly 25 pages and rising if applied to that file.**

### ⛔ The wrong copy, restated because it has already cost reps

**Never cite `raw\Textbook Doc Files\2e_Word\`.** It is a later flat 0–29 renumbering:
its Ch 3 is *Library and Internet Research* where the syllabus's Ch 3 is *Ethics*, and it is
missing chapters 25–28. Two `.ROOT` study pages taught from it until 2026-08-19. **This map
covers the decimal-numbered copy only**, which is the edition the §04 syllabus numbers

## How this was verified

`pypdf` text extraction across all 634 pages, matching section openers of the form
`N.M: Title` at the head of a page, cross-checked against the book's own Table of Contents
(physical p. 7), whose page references proved to be physical PDF pages.

**Three independent spot checks, all exact:** physical 149 → `2.13: Memos and Emails`;
physical 448 → `5.10: Strategies for Peer Reviewing and Team Writing`; physical 174 →
`Chapter 3: Ethics in Technical Communication`.

Four sections (5.1, 5.6, 5.8, 5.10) were first matched on the TOC page rather than their
opener; each was resolved from the TOC's own page reference and 5.10 was then opened to
confirm. Recorded here rather than smoothed over. Nothing in the tables is interpolated.

**Rule inherited from `PYTHON\wiki\source-page-map.md`:** any source added to this course
gets a row here at intake, with at least one page opened to confirm. *A chapter name is a
search; a physical page is a retrieval.*
