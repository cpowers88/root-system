# PYTHON

This wiki is the programming-language education hub: it turns books,
syllabi, documentation, and practice into a staged learning path — and holds
the durable record of what Chris can actually do. It is scoped to Python for
now because Python is the only language in active use; there is no duplicate
language infrastructure on the system to justify a separate wiki yet. If a
second language enters scope, extend this hub before splitting it — a rename
(e.g. "programming languages") is an open question, not a decision.

It supports CSE 1321/1321L now. The staged path, glossary, code patterns, and
capability library are built to outlast the course.

Start with:

1. `HOW_TO_USE.md` for the human workflow.
2. `wiki\current-position.md` for the live stage and frontier.
3. `wiki\learning-path.md` for the Stage 0–10 sequence.
4. `wiki\index.md` for the complete catalog.

`OPERATIONS.md` is the local contract for any AI working here.

Official course files stay in `04-SCHOOL\`. General non-Python
coursework belongs to `03-WIKIS\EDUCATION\`; physics to `03-WIKIS\PHYSICS\`.

`raw\` is immutable. CSE 1321/1321L explicitly prohibit AI-assisted submitted
work — see `wiki\syllabus-alignment.md`.
