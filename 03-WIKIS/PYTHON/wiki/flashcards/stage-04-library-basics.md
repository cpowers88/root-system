# Flashcard Batch: Stage 4 — Standard Library Basics

## Card: Standard library

**Front:** What is Python's standard library?

**Back:** Reusable modules that ship with Python and do not need a separate installation.

**Tags:** python, stage-04, standard-library

---

## Card: Import statement

**Front:** What does `import random` do?

**Back:** It makes the `random` module available under the name `random` in the current program.

**Tags:** python, stage-04, import

---

## Card: Module function call

**Front:** Why is the call written `random.randint(1, 6)` instead of only `randint(1, 6)` after `import random`?

**Back:** `randint` belongs to the `random` module, so the module name identifies where the function comes from.

**Tags:** python, stage-04, decision-rule

---

## Card: Import vs install

**Front:** Is `import` the same as installing a package?

**Back:** No. `import` loads available code; installation adds a third-party package to the environment.

**Tags:** python, stage-04, decision-rule
