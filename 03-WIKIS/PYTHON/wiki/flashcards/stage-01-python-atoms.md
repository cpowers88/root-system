# Flashcard Batch: Stage 1 — Python Atoms

## Card: Value

**Front:** What is a value?

**Back:** A single piece of data Python can work with — a number, text, or True/False.

**Tags:** python, stage-01, values

---

## Card: Expression

**Front:** What is an expression?

**Back:** A combination of values and operators that Python can evaluate down to a single value.

**Tags:** python, stage-01, expressions

---

## Card: Variable

**Front:** What is a variable?

**Back:** A name that points to a value, and can be reassigned to point at a different value later.

**Tags:** python, stage-01, variables

---

## Card: Assignment vs. Comparison

**Front:** What's the difference between `=` and `==`?

**Back:** `=` assigns a value to a variable. `==` checks whether two things are equal. They are never interchangeable.

**Tags:** python, stage-01, decision-rule

---

## Card: String

**Front:** What is a string?

**Back:** Text in Python — any characters wrapped in matching single or double quotes.

**Tags:** python, stage-01, strings

---

## Card: Concatenation

**Front:** What is string concatenation?

**Back:** Joining two strings together, usually with `+`, to form one longer string.

**Tags:** python, stage-01, strings

---

## Card: Integer

**Front:** What is an integer in Python?

**Back:** A whole number (no decimal point), represented by the `int` type.

**Tags:** python, stage-01, numbers

---

## Card: Float

**Front:** What is a float in Python?

**Back:** A number with a decimal point, represented by the `float` type.

**Tags:** python, stage-01, numbers

---

## Card: input() return type

**Front:** What type of value does `input()` always return?

**Back:** A string — always, even if the user types something that looks like a number.

**Tags:** python, stage-01, decision-rule

---

## Card: Why convert input?

**Front:** Why do you usually need to convert the result of `input()` before doing math with it?

**Back:** Because `input()` always returns a string, even if the user typed a number — you must convert it with `int()` or `float()` first.

**Tags:** python, stage-01, decision-rule

---

## Card: int() vs float() decision rule

**Front:** When should I use `int()` instead of `float()` to convert a string?

**Back:** Use `int()` when the value is always a whole number (like an age). Use `float()` when the value might have a decimal (like a price or measurement). `int("3.9")` will fail.

**Tags:** python, stage-01, decision-rule

---

## Card: print()

**Front:** What does `print()` do?

**Back:** Displays text or values to the screen.

**Tags:** python, stage-01, print-input

---

## Card: Comment

**Front:** What does a comment do in Python?

**Back:** Nothing to the program — Python ignores anything after `#` on a line. It's a note for humans reading the code.

**Tags:** python, stage-01, comments
