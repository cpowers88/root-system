# Flashcard Batch: Stage 4 — Functions

## Card: Function

**Front:** What is a function?

**Back:** A named, reusable block of code that runs when called.

**Tags:** python, stage-04, functions

---

## Card: def vs call

**Front:** Does writing a `def` block run the function's code?

**Back:** No — `def` only defines the function. The body runs only when the function is called.

**Tags:** python, stage-04, decision-rule

---

## Card: Parameter

**Front:** What is a parameter?

**Back:** A name in a function's definition that acts as a placeholder for a value it will receive when called.

**Tags:** python, stage-04, parameters

---

## Card: Argument

**Front:** What is an argument?

**Back:** The actual value passed into a function call, which gets assigned to the matching parameter.

**Tags:** python, stage-04, arguments

---

## Card: Parameter vs Argument

**Front:** What's the difference between a parameter and an argument?

**Back:** A parameter is the name in the function's definition. An argument is the actual value supplied at the call site.

**Tags:** python, stage-04, decision-rule

---

## Card: Scope

**Front:** What happens to a variable created inside a function once the function finishes?

**Back:** It disappears — it was local to that function's scope and isn't visible outside it.

**Tags:** python, stage-04, scope

---

## Card: Default return value

**Front:** What does a function return if it has no `return` statement?

**Back:** `None` — Python's way of saying "nothing."

**Tags:** python, stage-04, return-values

---

## Card: print() vs return decision rule

**Front:** When should a function use `return` instead of just `print()`-ing its result?

**Back:** Use `return` whenever the result needs to be used afterward — stored, calculated with, or passed to another function. `print()` only displays; it doesn't hand anything back.

**Tags:** python, stage-04, decision-rule

---

## Card: Fruitful vs void function

**Front:** What's the difference between a fruitful function and a void function?

**Back:** A fruitful function returns a usable value. A void function performs an action but doesn't hand anything back.

**Tags:** python, stage-04, fruitful-void
