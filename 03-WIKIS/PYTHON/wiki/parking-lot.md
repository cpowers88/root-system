# Parking Lot

## Purpose

This page protects the beginner path from advanced material.

Parked does not mean useless. It means not now.

---

## Parked Advanced Topics

| Topic | Why parked | Prerequisite needed | Revisit when |
|---|---|---|---|

| pandas | too advanced before files/data structures | lists, dictionaries, files | automation bridge |
| APIs | requires functions, dictionaries, JSON, errors | dictionaries, functions, errors | application thinking |

| CI/CD | production reliability topic | tests, Git, project structure | production stage |

| Image manipulation / graphs (Automate the Boring Stuff Ch.21) | niche, not core path | files, loops | Stage 10, optional |
| OCR / text recognition in images (Ch.22) | specialized, low priority | files, Stage 9 fluency | optional, only if Chris asks |

## Scope Creep Rule

When Chris asks a broad or advanced question, answer with:

1. the tiny version he can understand now,
2. the prerequisite path,
3. where it is parked,
4. the next beginner action.
