# tool-capability-library

This folder answers the vault's second controlling question: **what can code solve?** Each page maps a real-world problem category to the Python tools that solve it, at beginner level, with the advanced version explicitly parked.

Use these pages when Chris asks "could code do X?" — find the matching capability, teach the beginner version, park the rest.

## Capability Index

| Capability | Earliest stage | One-line answer |
|---|---|---|
| [[automate-decisions]] | 2 | Encode a repeated judgment as an `if`/`elif` rule and apply it to many items. |
| [[clean-text]] | 5 | Normalize messy names/text with string methods. |
| [[validate-data]] | 6 | Catch bad input with rules + `try`/`except` before it breaks anything. |
| [[organize-files]] | 9 | Sort a folder full of files into subfolders automatically. |
| [[read-write-spreadsheets]] | 9 | Read a CSV, compute totals/averages, write results. |
| [[generate-reports]] | 9 | Turn a data file into a formatted written summary. |
| [[call-apis]] | 10 | Pull live data from the internet as dictionaries. |
| [[build-small-tools]] | 10 | Wrap any of the above as a named CLI tool others can run. |

## Page Rules
