# Expression

## Plain-English Definition

Anything Python can evaluate down to a single value — a value by itself, or values combined with operators.

## What Problem It Helps Solve

Lets you describe a calculation or combination instead of writing out the final answer yourself.

## When Chris Will See It

Inside almost every line of code: math, building strings, comparisons.

## Code Example

```python
2 + 3 * 4
"a" + "b"
age >= 18
```

## Common Confusion

An expression isn't a full instruction by itself — it produces a value, but you usually still need to do something with that value (print it, store it, compare it).

## Physical-World Anchor

Like a math word problem: "3 apples plus 4 apples" is the expression; "7 apples" is the value it evaluates to.
