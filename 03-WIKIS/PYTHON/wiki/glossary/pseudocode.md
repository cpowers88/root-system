# Pseudocode

## Plain-English Definition

A plain-English (or loose code-like) description of a program's steps, written *before* any real code, to plan the logic without worrying about exact syntax.

## What Problem It Helps Solve

Lets you focus on getting the logic right first, separately from getting the Python syntax right — two different skills that are easier to do one at a time.

## When Chris Will See It

At the planning stage of any multi-step program, written on paper or in comments before the real code.

## Code Example

```text
1. Get a number from the user
2. If the number is even, print "even"
3. Otherwise, print "odd"
```

## Common Confusion

Pseudocode doesn't need to follow any strict syntax — it just needs to be precise enough that you (or someone else) could turn it into real code without guessing.

## Physical-World Anchor

A sketch before a final drawing — rough, but captures the actual plan before any "ink" (real code) is committed.
