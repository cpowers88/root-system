# `pip`

## Plain-English Definition

Python's package installer — the command-line tool used to download and install third-party packages.

## What Problem It Helps Solve

Gives a standard, reliable way to get third-party code onto your machine so it can be imported.

## When Chris Will See It

Run from a terminal, not inside a `.py` file: `pip install package_name`.

## Code Example

```bash
pip install pygame
```

## Common Confusion

`pip install` is run in the terminal, separate from running your Python script — it's a one-time setup step, not something that goes inside your program's code.

## Physical-World Anchor

Ordering a tool from a catalog before it arrives at your workshop — a separate step from actually using the tool once it's there.
