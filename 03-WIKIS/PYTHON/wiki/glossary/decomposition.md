# Decomposition

## Plain-English Definition

Breaking a big, vague problem into smaller, concrete steps that are each simple enough to code directly.

## What Problem It Helps Solve

A large problem is overwhelming to attack all at once. Decomposition turns it into a checklist of small, doable pieces.

## When Chris Will See It

At the start of any project bigger than a few lines — before any code is written.

## Code Example

```text
Problem: "Build a quiz program"
Decomposed:
1. Store a list of questions and answers
2. Ask each question
3. Check the answer
4. Track the score
5. Show the final score
```

## Common Confusion

Decomposition isn't the same as writing pseudocode — decomposition is identifying *what* the pieces are; pseudocode is writing out *how* each piece works in more detail.

## Physical-World Anchor

Breaking "clean the house" into "vacuum," "do dishes," "make beds" — each one is small enough to just start doing.
