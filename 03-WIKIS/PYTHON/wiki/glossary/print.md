# `print()`

## Plain-English Definition

A built-in function that displays text or values on the screen.

## What Problem It Helps Solve

Without it, a program could compute results but never show them to the person running it.

## When Chris Will See It

In nearly every program, to show output, results, or messages.

## Code Example

```python
print("Hello, world!")
print(2 + 2)
name = "Chris"
print(f"Hi, {name}!")
```

## Common Confusion

`print()` always needs parentheses in Python 3 — `print "hello"` (no parentheses) is Python 2 syntax and causes a `SyntaxError`.

## Physical-World Anchor

Like speaking out loud — `print()` is the program's way of saying something to whoever's watching the screen.
