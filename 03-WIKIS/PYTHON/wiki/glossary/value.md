# Value

## Plain-English Definition

A single piece of data Python can work with: a number, a piece of text, or a true/false answer.

## What Problem It Helps Solve

Every program is ultimately just moving, combining, and transforming values. It's the smallest unit of "stuff" a program handles.

## When Chris Will See It

Everywhere — every number, every bit of text in quotes, every `True`/`False` is a value.

## Code Example

```python
7
"hello"
3.14
True
```

## Common Confusion

A value is not the same as a variable. `age = 16` — `16` is the value; `age` is the name pointing at it.

## Physical-World Anchor

A value is like a single item — an apple, a price tag's number, a name written on a card.
