# Standard Library

## Plain-English Definition

The collection of reusable modules that ships with Python.

## What Problem It Helps Solve

It supplies dependable tools for common work—math, random values, dates, file
paths, CSV, JSON, and more—without requiring separate installation.

## When Chris Will See It

Whenever a script imports modules such as `math`, `random`, `pathlib`, `csv`, or
`json`.

## Code Example

```python
import math

answer = math.sqrt(81)
```

## Common Confusion

The standard library ships with Python. A third-party package is separate software
that usually must be installed and maintained.

## Physical-World Anchor

The set of tools included in the box when Python is installed.
