# Business Wiki Index

## Purpose

Root doorway for the Business wiki. This file exists so every `03-WIKIS`
hub has the same standard entry point: `wiki/index.md`, `wiki/log.md`, then
the domain-specific pages.

This wiki turns refined business, audit, pricing, sales, fulfillment, and
human-agent operating-model thinking into methods Chris can eventually use
with real clients. Blank strategy and master templates live here. Filled
client-specific/private artifacts live in a separate authorized client
workspace outside `.ROOT`; only sanitized reusable learning returns to
`05-BUSINESS`.

  sales, fulfillment: this wiki.

- Technology landscape and applied technical reference: `03-WIKIS\TECHNOLOGY`.
- AI/agent patterns and `.ROOT` self-evolution proposals:

## Current Standard

when an idea is reusable, North-Star-relevant, and does not fit an existing
page.
