# Audit Report Template

The Rung 1 deliverable ([[smb-ai-audit-method|SMB AI Audit Method, Step 5]]). 10–20 pages, presented live, never just emailed. Structure below; guidance in *italics*. The report must stand alone as worth its fee **and** function as the proposal for Phase 1.

---

# Operational Efficiency Audit — [Client Name]
**Prepared by:** [You/Firm] · **Date:** · **Scope:** [departments/processes covered]

## 1. Executive Summary *(1 page — write it last, present it first)*

> **We identified $[XX,XXX] per year of recoverable cost and revenue leakage across [N] processes.** The three largest: [Process A] ($X/yr), [Process B] ($X/yr), [Process C] ($X/yr). A phased plan below recovers ~[X]% of this within [X] months; Phase 1 pays for itself in [X] weeks.

*One paragraph on method (interviews, observation, volume analysis) and one on what's NOT included. Conservative numbers only — credibility is the product.*

## 2. How [Client] Works Today *(2–4 pages)*

*One process map per core flow (lead-to-cash minimum): trigger → steps → tools → handoffs → output, with time per instance and monthly volume annotated. A client seeing their own operation drawn accurately for the first time is the moment the report earns trust — accuracy here sells Phase 1 more than any pitch.*

**Systems inventory:** table of software in use, what it's used for, what it connects to (usually: nothing).

## 3. Findings *(3–6 pages — the core)*

*One block per finding, ranked by annual cost. 5–10 findings; more dilutes.*

### Finding [N]: [Plain-language title, e.g., "Quotes take 2 days because data is assembled by hand"]
- **What happens now:** *2–3 sentences, concrete.*
- **What it costs:**
  | Component | Calculation | Annual cost |
  |---|---|---|
  | Labor | [X min] × [N/mo] × 12 × [$/hr loaded] | $ |
  | Errors/rework | | $ |
  | Revenue leakage | *e.g., quotes lost to slow turnaround, estimated conservatively* | $ |
  | **Total** | | **$** |
- **Evidence:** *interview quote (unattributed), observed timing, volume source.*
- **Recommended fix:** *[named solution] — which pathway ([[workflow-automation-pathway|workflow]] / [[crm-and-sales-ops-pathway|CRM]] / [[document-automation-pathway|documents]] / [[data-and-dashboard-pathway|dashboards]]), what changes for staff, what stays human.*
- **Estimated cost to fix:** $[range] · **Payback:** [X months] · **Complexity:** Low/Med/High

## 4. Findings Summary Table *(1 page — the page owners photograph)*

| # | Problem | Annual cost | Fix cost | Payback | Complexity |
|---|---|---|---|---|---|
| 1 | | $ | $ | | |
| | **Total identified** | **$** | | | |

## 5. Recommended Roadmap *(1–2 pages)*

- **Phase 1 — Quick wins ([X] weeks):** *findings #_, #_ — lowest complexity, fastest payback.*
- **Phase 2 — Core systems ([X] months):** *the structural fixes.*
- **Phase 3 — Optimization & visibility:** *dashboards, assistants, continuous improvement — flagged, not scoped.*

*Also list findings you recommend NOT fixing yet and why (low ROI, prerequisite missing). Recommending against work is the strongest credibility signal in the report.*

## 6. Phase 1 Proposal *(1 page — the last page is the next sale's first page)*

> **Phase 1: [Name, e.g., "Quote Turnaround System"]**
> Fixes findings #[_]: currently costing **$[X]/yr**.
> Deliverables: *3–5 bullets, concrete.* · Timeline: [X] weeks · Investment: **$[X]** (50% to start / 50% at delivery) · Projected payback: [X] weeks.
> Includes 30 days of post-launch support; ongoing maintenance options presented at handoff ([[retainer-model|Retainer Model]]).
> Valid 30 days. To proceed: [signature/link].

## Appendix
*Detailed calculations, full process maps, interview methodology, assumptions log (every $/hr rate and volume figure sourced).*

## Presentation Notes (Internal)
- Walk the live meeting: headline number → their process maps → top 3 findings → summary table → roadmap → Phase 1. 45–60 minutes.
- Pause after the headline number; let them react. Their reaction tells you Phase 1 appetite.
- Close with the [[audit-sales-call-script|sales script's]] Phase 1 close, then stop talking.
