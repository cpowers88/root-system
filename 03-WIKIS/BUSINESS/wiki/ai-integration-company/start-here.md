# Start Here

> The bridge from reading this wiki to acting on it: your first week, your vertical decision, and the exact order to do things in.

## Timeline Gate — Read This First
This page describes what to do once Track 3 (this wiki) is actively running. Per NORTH_STAR.md's Business Arc, that clock starts at the **First Contact phase (~Sep 2026)**, with first client targeted for **March 2027** — not on whatever day you're reading this. Track 1 (school, non-negotiable) and Track 2 (Python/SQL, KSU Tracker, POL) come first, per the [[north-star-alignment|three-track order]]. If the calendar hasn't reached First Contact yet, the two decisions below are worth making now (they're cheap and reversible), but hold the outreach/LLC-filing/pipeline steps until the gate opens — right now, the correct daily work is school prep and the Track 2 builds.

## Purpose
Every plan dies in the gap between "I understand it" and "I started it." This page closes that gap: it tells you what to do **once the timeline gate above is open**, forces the two decisions that block everything else, and points you at the ready-made [[templates/template-library|templates]] so nothing has to be built from scratch.

## The Two Decisions That Block Everything Else

### Decision 1 — Pick your starting vertical (do this in one sitting, revise later)
Don't research your way to paralysis. Score 3–5 candidate verticals from the [[market-map|Market Map]] list on these five questions (1–5 each), pick the highest, and move:

| Question | Vertical A | Vertical B | Vertical C |
|---|---|---|---|
| Do I know anyone in it? (owner, employee, friend) | | | |
| Is it local/reachable to me? | | | |
| Is it operationally heavy? (quotes, scheduling, docs, invoices) | | | |
| Can these businesses afford $2.5K–$25K? | | | |
| Do I find it tolerable to think about for 2 years? | | | |
| **Total** | | | |

A score of 18+ is a green light. A tie? Pick the one where you know a real person — a warm first conversation beats a theoretically better market. This decision is **reversible after 5 audits**; it is not reversible if you never make it.

### Decision 2 — Set your commitment structure
Write down, today, in one paragraph:
- Hours per week committed (and *which* hours — on the calendar)
- Full-time trigger if starting on the side (e.g., "3 consecutive months ≥ $8K revenue")
- Runway: months of personal expenses covered (this sets how aggressive [[pricing-models|pricing]] and outreach need to be)
- The one metric reviewed every Friday (start with: outreach touches this week)

## Your First Week (Before the "First 30 Days" Clock Starts)

**Day 1–2: Decisions + setup**
- [ ] Make Decision 1 and Decision 2 above
- [ ] Do the [[business-setup|Business Setup]] quick tier: LLC filing started, separate bank account, password manager
- [ ] Set up the minimum [[tool-stack|tool stack]]: Make account, HubSpot free, Airtable

**Day 3–4: First artifacts**
- [ ] Copy the [[audit-intake-questionnaire|audit intake questionnaire]] and [[audit-interview-guide|interview guide]] into your own docs; customize for your vertical
- [ ] Write your positioning sentence: *"I help [vertical] businesses find and fix the manual work costing them $50–200K/yr — starting with a 2-week paid audit."*
- [ ] Build your first practice automation (your own contact form → CRM → notification)

**Day 5–7: First contact**
- [ ] List 25 warm contacts (you'll get to 50 in [[first-30-days|First 30 Days]])
- [ ] Send 5 messages using the warm-network script in [[outreach-scripts|outreach scripts]]
- [ ] Book 1 practice conversation with anyone who runs or works in a business — the goal is reps, not revenue

Then start the [[first-30-days|First 30 Days]] plan proper.

## Rules for Using This Wiki Without Drowning In It
- **Read pages when their step arrives, not before.** You need [[three-year-plan|Three-Year Plan]] in month 10, not week 1.
- **Templates over comprehension.** When a page says "create X," check [[templates/template-library|templates/]] first — most X's already exist there.
- **When stuck, default to outreach.** Almost every stall in the first 6 months is solved by more conversations, not more preparation. See [[risks-and-failure-modes|Risks & Failure Modes]] #15.
- **Friday review, 20 minutes:** fill in the [[weekly-scorecard|weekly scorecard]]. What you measure weekly is what actually happens.
