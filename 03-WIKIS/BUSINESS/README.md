## Phase view (tag filtering)

Every page carries exactly one **phase tag** as its first tag. The single `.ROOT` graph colors this folder as one block (see `.ROOT\.obsidian\graph.json`); to read phase progression, filter the graph search by tag instead of color — so the filtered view reads as a progression map, left to right through the business's life:

| Tag | Phase | When |
|---|---|---|
| `#phase-1` | Foundation | Weeks 0–4 |
| `#phase-2` | First clients | Months 1–3 |
| `#phase-3` | Deliver & convert | Months 3–12 |
| `#phase-4` | Expand | Years 1–3 |
| `#phase-5` | Scale | Years 3–10 |
| `#phase-all` | Always-on reference | Every phase |

**How to use it:** in graph view, type `path:"03-WIKIS/BUSINESS" tag:#phase-1` in the search filter to isolate the current phase's pages within this wiki; widen to `tag:#phase-1 OR tag:#phase-2` as you progress. Clicking a phase tag anywhere also lists that phase's pages. When a new page is added, give it one phase tag (first position).

## How the pages are structured

Every page follows the same skeleton so it can be skimmed or studied:

- **Purpose** — why the page exists
- **Key idea** — the one thing to remember
- **Why it matters** — the stakes
- **Practical actions** — what to actually do
- **Beginner version** — solo, learning, first clients
- **Intermediate version** — the loop running, first retainers
- **Advanced version** — with a team, scaling
- **Revenue connection** — how the page turns into money
- **Human-agent management connection** — how the page applies the operating thesis
- **Risks / failure modes** — what goes wrong on this page's turf
- **Related pages** — internal links
