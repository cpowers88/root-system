# The Elements of User Experience - Source Summary and Navigation Hub

**Source:** `raw/UserExperience.pdf`, Jesse James Garrett, *The Elements of
User Experience*, second edition (191 PDF pages).

## Why It Matters

The source provides a dependency model for product decisions: visual treatment
cannot rescue a wrong product objective, missing requirement, or broken
interaction structure. For Chris, it is a review framework for dashboards,
internal tools, client portals, and data-entry systems, not a separate design
curriculum.

## Use Gate

Use the five-plane review before implementation and again during usability
testing. Do not spend time polishing the surface while strategy, scope, or
structure remains unverified.
