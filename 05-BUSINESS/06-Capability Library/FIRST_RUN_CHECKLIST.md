# FIRST_RUN_CHECKLIST.md — Capability Asset Capture

Use this when turning a repeated method, checklist, script, query, or workflow map into the first real capability-library asset.

## Before Creating The Asset

- [ ] Confirm this is reusable, not a one-off note.
- [ ] Confirm the asset is client-facing or client-delivery-facing.
- [ ] Pick the primary APQC process area.
- [ ] Name the owner-facing business problem in one sentence.
- [ ] Identify the source: audit template, wiki page, field note, project, or practice run.

## Create The Asset

- [ ] Copy `APQC_ASSET_TEMPLATE.md`.
- [ ] Rename the copy using `APQC_[process-area]_[asset-name].md`.
- [ ] Fill required metadata: APQC process, asset type, business use case, maturity, source, next action.
- [ ] Write the problem in owner language, not technical language.
- [ ] Keep implementation notes practical: spreadsheet, Markdown, local script, existing tool, API, or low-cost automation.

## Close The Loop

- [ ] Add the new asset to `CAPABILITY_LIBRARY_INDEX.md`.
- [ ] Link back to the source material if it came from a wiki or audit template.
- [ ] Decide the test: practice audit, tracker/POL internal run, or real field observation.
- [ ] Set maturity honestly.
