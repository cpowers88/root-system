# 05-BUSINESS — The Money System (Reusable and Sanitized Assets)

Everything here must be **reusable across clients and safe to keep in `.ROOT`**:
blank masters, sanitized field learning, and capability assets. Active
client-specific/private work lives in a separate client workspace outside
`.ROOT`; only sanitized lessons, approved case studies, and non-sensitive
metadata return here. Strategy and business *research* live in
`03-WIKIS\BUSINESS`; raw business *reference* lives in `02-LIBRARY\REF-BUSINESS`.

## What Lives Where, and When It Fills

| Folder | Holds | State / first-fill trigger |
|---|---|---|
| `01-Audit Templates\` | Observation methodology, findings format, audit report template | Live (3 masters) |
| `02-Field Notes\` | Field-notes template + sanitized real observations | Live |
| `03-Case Studies\` | Approved, sanitized client case studies | **Empty by design** — fills after the first completed engagement with client approval |
| `04-Pricing Models\` | Pricing worksheets and models | Sparse (1 worksheet; numbers are Chris's to set) |
| `05-Proposals & SOWs\` | Blank proposal and SOW masters | **Empty by design** — fills when the first real prospect requires one |
| `06-Capability Library\` | APQC-indexed reusable client-facing assets with an honest maturity ladder | Live — see its own `README.md` and `CAPABILITY_LIBRARY_INDEX.md` |

## Rules of This Realm

1. No fake client folders before a real client, named prospect, or approved
   sandbox exercise (CASTLE OPERATIONS rule).
2. Asset maturity is stated honestly: idea / draft / tested internally /
   client-ready / deployed. Proof gates advancement past `draft`.
3. Every meaningful asset returns through the Return Packet
   (`01-NORTH_STAR\System Contracts\ROOT_CAPABILITY_CONTRACT.md § Return Packet`).
