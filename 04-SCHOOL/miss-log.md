## How to use it — 60 seconds, at the end of a study block

**Log a miss when a rep fails cold.** Not when something is merely hard, and not when you
looked something up on purpose. The bar is: *you attempted it as if it were graded, and it
would not have earned full marks.*

Fill five fields. The fifth is the one that matters:

1. **What was asked** — the actual prompt, not the topic.
2. **What you did** — the wrong move, written as the move, not as "got it wrong."
3. **Error class** — pick from the register below, or add a new one.
4. **Re-aimed next rep** — *not a re-run.* If the miss was equation **selection**, the next
   rep must force selection and remove everything else. A re-list of the same problem
   re-tests what already worked.
5. **Status** — `open` → `re-run scheduled` → `closed (durable)`.

**The rule that makes this worth keeping:** *the next study block opens with the oldest open
row in this log, not with today's date.* A miss that is never re-aimed is just a diary entry.

## Error-class register — the pattern is the point

Counts are what turn a list of bad days into a diagnosis. Update the count when you log a row.

| Error class | Count | What it looks like | The counter-move |
|---|---:|---|---|
| **Equation choice / units** | 1 | Reaching for a relationship that does not have the right dimensions — `a = (v_f − v_0)/Δx`, units s⁻¹ | Before substituting, say the units of the expression aloud. Wrong units = wrong equation, every time, no exceptions |
| **Concept — set structure** | 1 | Reciting a set of relationships and asserting it complete when a member is missing | Never recite the set. Present a problem missing one variable and select on the absence |
| **Cross-course rule contamination** | 1 | Answering a TCOM policy question with a PHYS rule — **and being confident** | The contamination card: *PHYS rewards foresight, TCOM rewards speed.* Name the course before answering any policy question |
| **Incomplete answer — direction / real force** | 1 | Correct magnitude, missing the vector direction and the physical agent supplying it | An acceleration answer is not finished until direction **and** the named force are stated |
| **Invented a rule where the source gives literals** | 1 | Generating a filename from a taxonomy when the syllabus prints exact strings and there is no generating rule | Ask first: *does the source state this, or am I deriving it?* Literals get copied character for character |
| **Reasonableness check not firing** | standing | Dropping or mis-substituting a value and carrying it to an answer that is never sanity-checked | Second road: differentiate back, estimate the magnitude, or re-substitute. **See the standing habit below** |
