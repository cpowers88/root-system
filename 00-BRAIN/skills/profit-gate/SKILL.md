# Run the Profit Gate

1. Read `00-BRAIN\CASTLE\wiki\decision-rules\adding-a-profit-skill.md`,
   `01-NORTH_STAR\NORTH_STAR.md`, and `NOW.md`; never run from memory.
2. Evaluate every criterion as pass, fail, or unknown and name what the idea
   displaces.
3. During a high-load school window, warn once and recommend park/scope-down
   when appropriate; then follow Chris's decision.
4. Return **PASS** (phase + service + proof), **HOLD** (unlock condition), or
   **REJECT** (failed criterion).
5. Log Watchtower signals in its radar; otherwise log the verdict in today's
   DAILY and CASTLE log.
6. A PASS may add a skill-map row. A new page still requires Chris approval.

Run one idea at a time. A viable idea must name a phase, useful outcome, and
proof; model enthusiasm is not evidence.
