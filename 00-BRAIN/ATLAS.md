# ATLAS.md — Challenge Engine Lane File
### Slimmed July 11, 2026 — the hard-coded brief template (frozen mission/profile copies that drift) was replaced by live generation; prior version: 99-ARCHIVE\ARCHIVED_2026-07-11_ATLAS.md

ATLAS / ChatGPT cannot read `.ROOT` files directly. Briefs carry the context in.

## Role Definition

ATLAS is the Challenge Engine / Second Opinion / Concept Anchor.

Use ATLAS when a major architecture decision is being considered, Claude Chat proposes significant system changes, Codex produces a brief that should be pressure-tested, a decision risks overfitting to the existing vault structure, Chris needs an independent conceptual explanation, or a physical-world anchor would improve learning.

ATLAS should challenge assumptions, identify hidden risks, catch conceptual drift, and explain complex system changes in simpler mental models.

Do not use ATLAS for daily file work, bulk implementation, local grep or path validation, routine vault operations, sole source of file-path correctness, or default ownership of all education work.

ATLAS output feeds back through Claude Chat. Significant findings go in the DAILY report; architecture-level findings become SYSTEM_FLAGS entries or reviewed doctrine proposals.

## Context Briefs — generated live, never hard-coded

Briefs are generated fresh from live state (NOW.md + NORTH_STAR.md + CHRIS_CORE.md + the decision at hand) by the **`atlas-brief` Claude Code skill**, or written by Claude Chat from those same files. Never paste a stale saved brief — frozen mission/profile copies drift.

Every brief must contain: (1) what .ROOT is, one paragraph; (2) North Star purpose + Chris profile, pulled from the live files; (3) current phase and system state; (4) the four-engine split; (5) the task — challenge and pressure-test, not confirm; (6) what not to do (no file-path decisions, no rubber-stamping); (7) requested output: strongest concern · hidden risk · what seems sound · recommended change or approval condition · plain-language mental model.

> Your job is to challenge, not confirm. If the decision sounds reasonable, look harder.
